# Debian_leb

1. Project Overview

This project is about making an old, low-end computer useful again by using Linux instead of relying on a resource-heavy operating system.

The goal is to create a lightweight, practical desktop environment that can handle everyday tasks such as web browsing, online research, and general computer use.

This project may also help other people who have older computers and cannot afford to upgrade their hardware.

2. Test Hardware

The setup uses the following hardware:

Component| Specification
CPU| AMD Sempron 145, 2.8 GHz
RAM| 2 GB
Storage| 80 GB HDD
Graphics| AMD Radeon 3000 / RS780L
Display| 1920 × 1080, 60 Hz

These specifications are important because performance on low-end hardware can be very different from performance on modern computers.

3. Why I Chose Linux

I had an old computer that struggled with Windows, especially during everyday use.

I wanted to make the computer useful instead of leaving it unused. Linux was a practical choice because it offers lightweight distributions and desktop environments that can run on limited hardware.

I chose Debian Minimal as my starting point because it provides a basic system without requiring a full desktop environment during installation.

4. Desktop Environment Experiments

After installing Debian Minimal, I experimented with different graphical environments and window managers.

I used Openbox, which is a lightweight window manager. It worked well with my limited hardware, but its default experience required more manual configuration.

For this project, I decided to use LXQt instead.

LXQt provides a more complete and beginner-friendly desktop experience while remaining relatively lightweight. This makes it a useful option for people who want a traditional desktop without configuring everything manually.

5. Project Goals

- Build a usable desktop environment on low-end hardware.
- Keep memory and CPU usage reasonable.
- Make everyday tasks such as browsing and research practical.
- Document the installation and configuration process.
- Share performance observations and troubleshooting notes.
- Help other users understand what older hardware can still do.

6. Performance Testing

I will evaluate the system using practical observations and measurements, including:

- Idle RAM usage.
- CPU usage while idle.
- Desktop responsiveness.
- Web browsing performance.
- Application startup time.
- Overall usability during everyday tasks.

I will add actual measurements after testing rather than guessing or inventing benchmark results.

7. What I Hope to Learn

This project is not only about installing Linux. It is also an opportunity to learn about desktop environments, window managers, system resource usage, package management, and Linux configuration.

8. Conclusion

Older hardware does not automatically become useless just because it struggles with modern operating systems.

With a lightweight Linux distribution and a suitable desktop environment, an older computer may still be useful for everyday tasks.

This project documents my attempt to make that possible using Debian Minimal and LXQt.
